# Next-Gen Blood Bank System

A complete, responsive blood bank management platform for donor registration, blood requests, inventory, camps, and administration.

> Developed from the repository's "Next-Gen Blood Bank System Blueprint" specification.

## Features

- Public website with blood request and donor registration
- Role-based dashboard for admin, lab, inventory, and camp staff
- Blood stock and expiry management
- Compatibility-aware request matching
- Camp scheduling and venue management
- Donor eligibility and appointment workflows
- Audit trail and privacy-conscious access control
- Printable patient reports and operational dashboards

## Technology

- Next.js 14+
- React
- TypeScript
- Tailwind CSS
- In-memory demo data (replaceable with PostgreSQL/Supabase)

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Demo roles

The interface includes dashboards for:

- Hospital staff
- Blood bank administrator
- Laboratory staff
- Inventory manager
- Camp coordinator

## Safety

This project is a software planning and workflow platform. Final clinical eligibility, transfusion decisions, regulatory compliance, traceability, and medical validation require qualified healthcare personnel and locally applicable blood bank regulations.
